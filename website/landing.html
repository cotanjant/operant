Command Line Interface

Ergonomic Rust CLI with Clap

Interact with Operant directly from your shell. Supports one-shot execution, interactive terminal chat, and serving the API.

Start Inference Server

operant serve

Launches the OpenAI-compatible HTTP server on 0.0.0.0:8000 using pure Rust and Axum.

# Using cargo
cargo run -- serve --model-file ../model/out --port 8000

# Or the original baseline syntax
cargo run -- --model-file path/to/model

Terminal Chat Session

operant chat

Interactive multi-turn REPL with streaming tokens directly to stdout.

cargo run -- chat --model-file ../model/out

User > Plan a database migration safely.
Operant > 1. Dump schema 2. Apply idempotently...

One-Shot Generation

operant run

Execute single prompt completions for automation scripts and pipelines.

cargo run -- run --prompt "Who am i?"

# Output:
king

operant info

API Documentation

OpenAI-Compatible Inference API

Any application, SDK, or agent tool that speaks the OpenAI protocol can talk to Operant without code changes.

POST /v1/chat/completions Binds to 0.0.0.0:8000
Examples: 
curl -X POST http://localhost:8000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -d '{
    "model": "operant",
    "messages": [
      {"role": "user", "content": "What is the capital of Turkey?"}
    ],
    "temperature": 0.7,
    "max_tokens": 128
  }'
from openai import OpenAI

client = OpenAI(
    base_url="http://localhost:8000/v1",
    api_key="none"  # Local self-hosted
)

response = client.chat.completions.create(
    model="operant",
    messages=[{"role": "user", "content": "Explain KV caching."}],
    stream=True
)

for chunk in response:
    print(chunk.choices[0].delta.content or "", end="")
let client = reqwest::Client::new();
let res = client.post("http://localhost:8000/v1/chat/completions")
    .json(&serde_json::json!({
        "model": "operant",
        "messages": [{"role": "user", "content": "Hello Operant!"}]
    }))
    .send()
    .await?
    .json::<serde_json::Value>()
    .await?;

println!("Response: {}", res["choices"][0]["message"]["content"]);
Engineering

Model Card & System Architecture

Built upon Google's Gemma-3 architecture, optimized for local execution with pure-Rust tensor execution.

Gemma-3 Hybrid Attention Architecture

Operant utilizes an alternating pattern of sliding window local attention (512 tokens window) and full global attention every 6th layer. This enables efficient long-context processing while reducing computational footprint.

Hidden Size 640
Layers 18
Heads (Q / KV) 4 / 1 (GQA)
Head Dim 256
Vocab Size 262,144
Sliding Window 512

Philosophy

  • ✓ Agentic Native: Fine-tuned with planning, decomposition, and tool-calling examples.
  • ✓ Candle Powered: Pure Rust tensor operations, safe memory management, zero Python bindings.
  • ✓ Ponytail Mode: Minimal clean changes, eliminating needless wrappers or premature complexity.
Fine-Tuning

Reproducible Python Training Pipeline

Managed with uv, PyTorch, and Hugging Face Transformers. Outputs Safetensors directly consumable by Rust.

# 1. Inspect or expand dataset
cd model
uv run python src/model/generate_data.py

# 2. Run fine-tuning
uv run model # or python -m model

# 3. Model weights and tokenizer saved automatically to out/
ls -lh out/ # model.safetensors, config.json, tokenizer.json
